Foko Lab tutorial

Using Foko Lab without guessing

This guide is intentionally compact. Each example gives the action, the expected result, and the failure mode to check. For the PDF version, use Export tutorial as PDF and choose Save to PDF.

Common layout: choose a model on the left, edit/run in the middle, inspect plots and exports on the right.

1. Start from the Model Atlas

Open Model Atlas. Pick a card such as Lorenz, Toggle switch, SIR endemic equilibrium, or Birth-death CTMC.

Expected: the card opens the correct lab with ?example=... in the URL.
Check: if the wrong lab opens, the atlas card route is wrong.

2. ODE Lab: run Lorenz

Open ODE Lab, load Lorenz, and press Run.

Expected: two plots appear. The metrics row shows steps, evaluations, CPU time and tolerance.

Use plot selectors to switch between trajectory, phase plot, vector field, Poincaré section, and other views.

3. ODE Lab: parameter sweep

Switch to Parametric ODE and run a sweep example.

Expected: the right workspace shows a heatmap/contour-like response surface.
Numerical warning: browser RK methods are exploratory for stiff systems. Export to Python for Radau, BDF or LSODA validation.

4. Steady-State Lab: equation syntax

Use one equation per variable. The app solves each expression as equal to zero.

C: quad konES − koffC − kcatC = 0
x: quad ax − bxy = 0
y: quad dxy − cy = 0

The parser normalizes labels, unicode minus, quad, implicit products and =0.

Parsed as:
C: kon*E*S - koff*C - kcat*C = 0
x: a*x - b*x*y = 0
y: d*x*y - c*y = 0
Check: the preview must never display raw \[4pt].

5. Steady-State Lab: solve and classify

Choose Toggle switch bistability and press Solve.

Expected: equilibrium bar plot, Newton residual plot, residual norm and iteration count.

Local Jacobian classification is only a dynamical-stability statement if the equations are interpreted as dx/dt = f(x,p).

6. Steady-State Lab: continuation

Choose a continuation parameter, set min/max/points, then press λ Continuation.

Expected: branch plot on one side and continuation residual on the other.
Limitation: simple continuation can miss folds or switch branches. Use it as exploratory analysis.

7. Stochastic Lab: CTMC ensemble

Open Stochastic Lab, choose Birth-death, set runs to 200, and press Run ensemble.

Expected: the primary plot shows paths or mean trajectory. The secondary plot shows distribution or diagnostics.

Events that would make counts negative are blocked before firing, not clamped afterward.

8. Stochastic Lab: mean-field overlay

Enable Mean-field overlay and select Mean + mean-field.

Interpretation warning: mean-field is a deterministic large-count approximation. It can fail near extinction, low copy numbers, or strong nonlinear propensities.

9. Optimization Lab: convex bowl

Choose Convex bowl, set a seed, and press Optimize.

Expected: samples move toward x≈2, y≈-1. Repeating with the same seed should reproduce the same trajectory.

For constrained templates, inspect both objective and feasibility metrics.

10. Optimization Lab: incompatible plots

Some plots require specific model content.

  • Pareto: requires a secondary objective.
  • Feasibility: is meaningful for constraints.
  • Variables: uses candidate traces and can be noisy for stochastic search.
Trust rule: browser optimization is approximate. Validate scientific conclusions externally.

11. Exports

  • Model JSON: exact editable model state.
  • Wide CSV: spreadsheet-friendly output.
  • Long CSV: tidy data for Python/R.
  • Plotly JSON: figure recreation.
  • Python starter: external validation scaffold.

12. Failure checklist

  • Plot area still says “Run to plot” after a run: check console, selected plot type, or Plotly loading.
  • Steady solve fails: inspect parsed equations and unknown symbols.
  • Continuation gives blank plot: run a solve first, then continuation.
  • Stochastic paths stop early: inspect maxEvents warnings.
  • Optimization result is infeasible: increase budget or inspect constraints and penalty scale.
