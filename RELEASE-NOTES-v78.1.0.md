# FokoLab v78.1.0 — identity and programme integration

Status: **release candidate**. No live repository or deployment changed.

## Implemented changes

- One production mark and wordmark across primary pages, specialist shell and favicon. The former cube is replaced by an F-shaped model path with an observed endpoint.
- Ink, copper, sage, paper and white visual system; coherent line icons; lighter page structure; removal of repeated shell copy, competing navigation and unnecessary card decoration. Scientific warnings remain.
- Compact five-destination navigation: Overview, Workspace, Library, Learn and Programme. Home exposes Create, Import, an explicitly analytic preview and four research starting points.
- Programme preserves all 27 chapter titles and seven parts from Scientific Mastery V6.16. Its four evidence gates link chapters to browser experiments and research artifacts without pretending to implement every external framework.
- Four original research threads: fatty-acid bistability, fatty-acid synthesis, photosynthesis and climate, T-cell proliferation. FokoLab remains the delivery/independent-usability thread.
- Local, validated evidence-note export/import. Optional local PDF selection and edition check; no private PDF or full companion notebooks published.
- Search Escape now closes a populated search field on the first keypress and restores the opener; a capture-phase regression covers the native search-input behavior.
- Numerical computation, model limitations, existing specialist tools, plot families and independent Two-up/Focus modes retained.

The two rendered suites use original-source in-memory Chromium fixtures with explicitly simulated storage and the bounded main-thread computation fallback. They are not a native HTTP, Worker, persistence, WCAG, real-device or live-deployment certificate. Screenshots are captures of those fixtures, not graphic mockups. The site build count and local reference checks are recorded in `validation-v78.1.0/pages-build.log` and the artifact's `PAGES_MANIFEST.json`.

Tests that asserted the removed cube, obsolete palette, page titles, versions or page counts were migrated to the actual replacement contracts. Numerical expected values and tolerances were not relaxed. Earlier diagnostic failures are retained as first-pass evidence, not erased or labelled passed.

## What is not claimed

This is not a rewrite of every specialist lab. No new neural training engine, hosted LLM service, protected research implementation or empirical validation was added. Course progress is not a competency certification. The full source PDF is local-only and absent from the deployment artifact. Full native browser testing, real devices, screen readers and live Pages remain outstanding.

The primary interface uses native fonts. Legacy KaTeX mathematical typefaces are external version-pinned dependencies and were not fetched in this environment; test equation rendering online before public release. See `LIMITATIONS-v78.1.0.md`.
