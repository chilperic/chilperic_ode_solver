# FokoLab recovery note

The public website is in `site/`; `docs/` mirrors the GitHub Pages build.

Recovered public applications remain available for cell, lipid, random-process and general evolutionary teaching workflows.

The unpublished plant and leaf research implementations were subsequently removed from the current public tree. Their public routes now provide non-reconstructive research overviews only. Public recovery evidence has also been redacted so that detailed plant/leaf configurations are not distributed with the site.

Historical recovery records do not constitute biological validation.
