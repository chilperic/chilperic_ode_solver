# V71.15 — ODE fitting execution, parameter CI, trajectory bands

## Scope
This release groups only tightly coupled scientific changes for the focused ODE Lab:
real ODE parameter fitting, parameter confidence intervals, and uncertainty bands on trajectory plots.

## Preserved
- No descriptor migration of Focused Labs.
- No route redirects.
- Existing Statistics, Linear Algebra, Fitting, Networks, and ML shell ports remain unchanged.
- Stochastic, Optimization, and Steady-State remain preserved standalone pages.

## Implementation
- Added a `fitOde` worker job.
- Added a visible `Fit ODE` action in `ode.html`.
- Fitting uses bounded finite-difference Levenberg-Marquardt-style updates over selected ODE parameters.
- Observed columns are matched to ODE variable names and residuals are computed against interpolated model trajectories.
- Parameter CI uses the local covariance approximation `sigma^2 (J^T J)^-1`.
- Uncertainty bands are generated by re-solving the ODE at CI perturbations.

## Known limits
This is local least-squares fitting, not global inference. It is sensitive to initial guesses, parameter bounds, and data quality. Bootstrap/profile likelihood and full Bayesian inference remain later releases.
