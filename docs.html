Core workflow

  1. Choose ODE, stochastic CTMC, optimization, steady-state, symbolic, agent or SciML.
  2. Load a curated model or import your own JSON.
  3. Edit initial conditions, parameter values, ranges, solver/setup values and the diagnostic target.
  4. Run one baseline case.
  5. Add only plots that answer a modeling question.
  6. Export JSON, CSV, Python, SymPy/SciPy or figures for validation outside the browser.

ODE Lab

Use ODE models for continuous deterministic dynamics. A strong workflow includes solver choice, stiffness awareness, event handling, phase portraits, vector fields, parameter sweeps, sensitivity analysis and calibration against data.

Optimization Lab

Use optimization models for objectives, constraints and trade-offs. The Workbench exposes initial guesses, bounds, parameter values, method family, population/starts, tolerance and seed. Use gradient-based methods for smooth problems and metaheuristics for rugged or multimodal landscapes.

Steady-State Lab

Use steady-state models for algebraic balances, roots, equilibria, residual checks, local Jacobian stability, continuation and sensitivity. A converged residual is not automatically a scientific validation.

Stochastic Lab

Use CTMC and Gillespie-style models when event timing and random trajectories matter. Always inspect ensemble paths, final distributions, extinction probabilities, run count, seed and deterministic comparison.

Symbolic Lab

Use symbolic computation for exact differentiation, simplification under assumptions, Jacobians, Taylor expansions, equation inspection and code generation. Rendered mathematics is the primary output; raw LaTeX should not be the user-facing result.

Agent Lab

Use ABM for decentralized systems with heterogeneous local rules, spatial grids, contact networks and emergent behavior. Validate through repeated runs, summary statistics, calibration and ODD-style documentation.

SciML Lab

SciML bridges mechanistic models and data-driven learning: inverse problems, surrogate modeling, SINDy, PINN/UDE export scaffolds, residual plots, loss curves, train/validation splits and uncertainty-aware diagnostics.

Scientific limits

Browser execution is for exploration and teaching. Use exported local scripts for stiff systems, large ABMs, large CTMC ensembles, publication-quality inference, uncertainty quantification and HPC workflows.

Custom models

Custom models can be imported through JSON in the Workbench. Current browser authoring is strongest for ODE and 2D optimization; CTMC, steady-state, symbolic and agent models have dedicated pages and export routes while the full Workbench authoring contract is consolidated.

Agent execution limits

Custom Agent Lab rules run in agent-rule-worker.js with a worker timeout. Multilayer spatial/social/transport contacts are supported for browser-scale tests, but large ABM studies should be exported or reproduced externally.

Plot standard

Put plot controls directly above the graph, keep variables selectable, and do not treat a decorative plot as evidence. Use the simplest diagnostic that can reject the current model assumption.

What every model should expose

Inputs

State variables, population size, initial conditions, parameter values, bounds, solver/setup, seed and time horizon.

Diagnostics

Trajectory, phase portrait, residual, convergence, sensitivity, sweep, uncertainty, feasibility and validation plots.

Export

JSON for reproducibility, CSV for results, Python/SciPy/SymPy/PyTorch scaffolds for serious local computation.
