# v21 · Agent Atlas + compact Agent Lab

## Audit finding
v20 made Agent Lab functionally richer but overcrowded the page. The long approach descriptions belonged in the Model Atlas, while the execution page needed selectors, visible parameters, and fast model switching.

## Changes
- Rebuilt Agent Lab into a compact selector-driven execution surface.
- Kept A-D parameters visible in a horizontal parameter strip.
- Moved approach comparison and long rule/model authoring text into collapsible panels.
- Added an Agent Model Atlas section to the Model Atlas.
- Added scenario links that open Agent Lab with a selected example via query string.
- Added additional Agent Lab examples: fatty-acid de novo particle agents, vaccine hesitancy, evacuation panic, meme-stock cascades, cancer-care myths, gentrification hype, deepfake polarization, poaching networks, AV backlash, smart-grid rumors, ancient cult/migration rumors.
- Added family filtering in Agent Lab.

## Boundary
Social/cultural/crisis examples are didactic ABM prototypes. They are not calibrated social-science models.
