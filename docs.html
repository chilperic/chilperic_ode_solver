Docs

Choose a route.

Pick a model type, run a small case, inspect the result, then export when the browser is no longer enough.

Core workflow

  1. Choose a route from Workbench or Legacy.
  2. Load an example or paste a model.
  3. Run one diagnostic case.
  4. Add plots only when they answer a specific question.
  5. Export JSON, Python, SymPy, SciPy or figures when needed.

Custom models

Each lab exposes an authoring route. Browser execution is suitable for small models. Use exports for stiff ODEs, large ABMs, calibrated inference, full sensitivity analysis or publication work.

Agent Lab

Use Agent Lab for grid, local-rule and contact-network simulations. Multilayer spatial/social/transport contacts are available for browser-scale tests. Custom rules run in agent-rule-worker.js with a worker timeout.

Plot standard

Use the simplest plot that answers the question. A browser plot is an exploratory result unless it is validated externally.

Scientific limits

Use browser plots for exploration. Use exported scripts for stiff systems, large simulations, calibration or publication-grade results.
