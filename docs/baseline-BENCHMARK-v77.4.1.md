# Foko Lab v77.4.1 — modeling-platform benchmark

This is an engineering and product-positioning checklist, not a claim of numerical or feature parity with specialist packages.

| Dimension | Foko Lab target | Specialist reference context |
| --- | --- | --- |
| Scientific reliability | Finite-input validation, assumptions, diagnostics, independent references and honest capability labels | COPASI, Tellurium, VCell, SimBiology |
| Model ownership | Blank authoring, editable equations/rules, parameters, initial conditions, time spans, outputs and numerics | COMSOL/Simulink-style model workflows |
| Platform stability | Canonical computation paths, vendored browser runtime, deterministic gates, explicit unsupported failures | Mature desktop/server environments |
| UX | Resizable authoring/results workspace, task rail, keyboard/touch navigation, responsive phone workflow | Modern scientific workbenches |
| Modern GUI | Responsive scientific canvas, adaptive subject/lab identity, local LaTeX, contextual 3D and semantic visualization controls | Contemporary modeling applications |
| Model interchange | TXT/ODE, JSON, object/dictionary, YAML, CSV and bounded standards paths | BioUML, VCell, COPASI, Tellurium |
| Population/evolution | Genetics, agent simulation, fitness landscapes and contextual live 3D | Cell Collective and specialist population/ABM tools |
| Analysis breadth | Sobol/Morris multi-output GSA, fitting, statistics, CMA-ES, Bayesian references, AI/SciML | Specialist methods remain deeper |
| Identity coherence | One State Observatory system with adaptive subject/lab context and independent scientific plot palettes | Product-level navigation clarity |

The competitive criterion is coherence: a user's model should remain the same scientific object as it moves from definition to simulation, analysis, diagnostics, visualization, and export. The Model Atlas supports that workflow; it is not the primary product surface.

Foko Lab does **not** claim numerical or feature parity with COMSOL, MATLAB/Simulink/SimBiology, VCell, COPASI, Tellurium, Cell Collective, BioUML, Stan/PyMC, SALib, SciPy, or dedicated HPC solvers.
