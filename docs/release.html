Release 80.0.0

Unified FokoLab

This release redesigns the visual and navigation architecture while retaining the established modeling and analysis workspaces. The expanded experiment laboratories are integrated as first-class scientific workspaces rather than a separate minimal interface.

What changed

New dynamic-systems master identity; semantic emblems for laboratories; unified experiment library; expanded seasonal plant, leaf, adaptation, lipid, T-cell, randomness, branching, diffusion and fractal configurations; one navigation model across original and newer laboratories.

Scientific boundary

Visual redesign does not establish scientific validity. Teaching reductions remain labelled as such. Original model equations and methods remain available where previously retained, and numerical evidence is separated from empirical validation.
