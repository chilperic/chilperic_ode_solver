# Foko Lab v77.4.1 — identity and integration audit

## Decision

The previous Model Space cube was legible but reductive: it described structured computation while under-representing dynamics, uncertainty, populations, evolution and the breadth of a general modeling platform. v77.4.1 therefore does not iterate the cube. It replaces it with the **State Observatory**, a responsive identity built around several scientific representations of one model state.

The flagship emblem contains a continuous response/dynamical manifold, nested inference/uncertainty contours, a discrete population/agent lattice, one observable-state axis, and a branching evolutionary path. The vertical state axis plus the upper planes imply an abstract `F`; the evolutionary split suggests `K`, a subtle Foko Kuate signature that remains secondary to the scientific reading.

## Scientific and UX safeguards

- Lab and subject colour remain navigation identity, never numerical magnitude.
- Plot palettes remain semantic and independent from the GUI identity.
- The identity avoids brain, gear, quantum, neural-cloud and generic AI symbols because Foko Lab is a general scientific modeling workbench.
- “Validation” is a visible platform workflow, not an automatic claim that an arbitrary user model has been scientifically validated; the lockup pairs it with “compute evidence · challenge assumptions.”
- The rich flagship is intentionally not used unchanged at 16 px; responsive simplification is part of the system.
- SVG assets contain accessible titles and descriptions; forced-colour CSS maps the adaptive mark to system colours.
- No solver, estimator, model preset, scientific tolerance, numerical reference or capability claim was changed for this brand release.

## Release boundary

This release is an identity-system and integration change. All active numerical, scientific-core, model-interchange, layout, accessibility and independent-reference gates remain mandatory before packaging. A Playwright/Chromium result is claimed only when the full browser suite actually runs.
