# Foko Lab v77.3.0 — identity change audit

## Decision

The v77.2 faceted Woven State mark was genuinely different from earlier trajectory logos, but it remained visually abstract and did not communicate the platform's central object strongly enough: a user-defined mathematical model. The v77.3 identity therefore changes the visual grammar again rather than iterating the tessellation.

The **Model Space Mark** is an open isometric coordinate volume. Its stable frame represents a model/state space; the structural `F` makes Foko intrinsic to the geometry; the ochre cell represents a state currently being simulated, optimized or inferred. Subject and lab colors occupy separate edges without changing the silhouette. The mark is not a brain, gear, particle vortex, neural network or “AI” badge because those would misrepresent the breadth of the platform.

## Product-logo checks

| Check | Decision |
| --- | --- |
| 16–32 px recognition | Keep the outer volume and F dominant; the state cell is secondary |
| Header recognition | One 42 px adaptive mark plus compact `Foko Lab` wordmark |
| Lab identity | Exact-lab and subject colors affect edges, never the structural silhouette |
| Scientific plots | GUI identity remains independent of quantitative/semantic plot palettes |
| Accessibility | SVGs are titled/described; forced-colors mode maps geometry to system colors |
| Print/monochrome | Dedicated monochrome geometry retains the same model-space structure |
| Cultural claims | No named or copied traditional motif is used |

## Scientific boundary

This release changes identity assets, runtime brand geometry, release metadata and brand regression contracts. It does not alter numerical algorithms, reference tolerances, model presets, sensitivity estimators, solvers or scientific capability claims. The unchanged numerical gates must pass before packaging.
