# UX audit v47

## Main inconsistency fixed
The previous v46 interpretation placed Symbolic and Agent mainly in a Workbench page card map. That was wrong because it looked like documentation and duplicated the Legacy concept. The corrected interaction puts Symbolic and Agent in the Workbench dropdown and in the Workbench model selector.

## Remaining risk
The native HTML select becomes long because it contains many examples. This is acceptable as a quick browser-native control, but the better future version is a searchable command palette with grouped approaches.

## Navigation contract
- Workbench: Model, Symbolic, Agent, Model Atlas.
- Legacy: ODE, Optimization, Steady-State, Stochastic.
- Learn: Docs, Tutorial, Platform.
- About: Research, Mathematical Beauty, Acknowledgement, Contact.
