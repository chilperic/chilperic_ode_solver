Lotka–Volterra

Predator–prey oscillator. The key lesson is how interaction terms create cycles in a phase portrait.

Authors / inspiration: Edward N. Lorenz

A canonical three-state chaotic system. Small changes in parameters or initial conditions can reshape long-term trajectories.

How to use this atlas

Use the atlas to choose a model, then open it in the workbench. The workbench is where you edit equations, run simulations, sweep parameters, configure figures, and export Python.

Boundary: research and paradox examples are reduced browser models for exploration. For calibrated fitting, stiff systems, or publication analysis, export Python.
