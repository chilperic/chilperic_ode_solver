Count mode requires integer state counts that sum exactly to grid size². Fraction mode uses deterministic largest-remainder allocation and records the resulting exact counts.

Custom local transition model

Custom models use ordered first-success local transitions. Supported rule kinds are spontaneous, neighbour-contact and neighbour-threshold. Arbitrary JavaScript is not executed.

Probabilities are per selected-site update attempt under the chosen schedule, not calibrated physical rates.

Grid, topology and ensemble

Random-sequential lattice updates. One simulation step is one lattice sweep: grid-size² update attempts under the selected schedule. It is an algorithmic clock, not automatically biological, social or physical time.
