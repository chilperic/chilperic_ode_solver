Chilperic Dynamics documentation

A browser workbench for deterministic ODE modeling, stochastic simulation, model exploration, and reproducible teaching-scale exports.

Quick start

  1. Use ODE Lab for differential equations, parameter sweeps, phase portraits, optimization, and Python export.
  2. Use Stochastic Lab for random-event models, ensembles, distributions, extinction/fixation probabilities, and stochastic diagnostics.
  3. Use Model Atlas to choose a curated deterministic or stochastic example and open it in the appropriate lab.
  4. Run the model, inspect the plots and diagnostics, then export JSON, CSV, figures, or starter Python where available.

ODE Lab

ODE Lab supports trajectories, 2D/3D phase portraits, vector fields, Poincaré sections, trajectory matrices, heatmaps, parametric sweeps, and constrained optimization experiments.

The browser supports Euler, Heun, RK4, RK5, and RK45-style adaptive integration. Python export supports SciPy solve_ivp targets such as RK45, DOP853, Radau, BDF, and LSODA.

Stochastic Lab

Stochastic Lab supports editable random-event models, custom CTMC/Gillespie model creation, ensemble simulation, deterministic mean-field comparison for CTMC models, and reproducibility exports.

  1. CTMC / Gillespie: create your own model from states, numeric parameters, propensities, and integer updates; or start from birth-death, SIR, gene expression, Michaelis-Menten, and reduced T-cell proliferation examples.
  2. Branching and finite Markov chains: Galton-Watson, Gambler’s ruin, Ehrenfest urn, and Wright-Fisher drift.
  3. SDE and fluctuation models: geometric Brownian motion, stochastic resonance, Parrondo’s paradox, and Brownian ratchet examples.
  4. Decision examples: multi-armed bandit and secretary/optimal-stopping simulations.

Custom CTMC events use Math.js-style mathematical expressions. Example: beta*S*I/N with visual per-state update entries such as S:-1 and I:+1. State and parameter names must be valid identifiers such as S, I, beta, or k_on.

Import formats

Use JSON for the most reliable model interchange. CSV, TXT/ODE, YAML-like files, Python files with an embedded ODE_LAB_CONFIG block, and basic SBML/XML reaction models are also supported.

SBML import handles species, reactions, stoichiometry, global/local parameters, and MathML kinetic laws. Events, algebraic rules, assignment rules, units, and advanced SBML packages are outside the browser import boundary.

Export publication figures

  1. Run a model or parameter sweep.
  2. Choose the primary or secondary view.
  3. Open Figure settings.
  4. Edit the title, axis labels, colorbar label, size, font, line width, marker size, legend, and grid.
  5. Export SVG for manuscripts or PNG for slides.

Modeling boundary

  • Use deterministic models when average population or concentration dynamics are the main object.
  • Use stochastic models when discreteness, extinction, hitting times, rare events, finite-population fluctuations, or information-gathering policies are central.
  • For calibrated inference, stiff systems, large ensembles, or serious constrained optimization, export and run a specialist Python workflow.
