0. Choose the correct surface

Use Workbench when…

You want to run common analyses from one model-centered page: parameter changes, time courses, sweeps, contour/heatmap, GSA/sensitivity, diagnostics and exports.

Use Legacy Lab when…

You need the complete original specialist interface, advanced controls, or behavior that is not yet migrated to the workbench.

Rule: Do not search through long controls first. Start from a model card and choose the appropriate route.

Open the model

Open SIR epidemic in Workbench.

Expected: analysis cards can be refreshed without searching through a left control column.

Use Time course first, then run Parameter sweep or GSA/sensitivity.

Expected: plots and ranked tables appear inside their own cards.

3. Stochastic path

Open stochastic SIR

Open stochastic SIR in Workbench.

Expected: ensemble, final distribution, stochastic sweep, sensitivity and reaction math cards.

Interpret ensemble output

Use mean trajectory and distribution cards together. Do not interpret one trajectory as the expected behavior.

Use legacy for specialized models

Open Stochastic Lab when you need the full CTMC/Gillespie specialist interface.

4. Steady-state path

Open an equilibrium model

Open enzyme steady-state, toggle steady-state, or cubic bistability.

Run response analysis

Use the MCA/GSA-style card to inspect parameter response. Treat it as a local response screen unless exported and validated externally.

Check stability language

Local stability classification is meaningful when the algebraic system is interpreted as dx/dt = f(x,p).

5. Optimization path

Open a benchmark

Open Rosenbrock, Rastrigin, or constrained optimization.

Read the right metric

For optimization, the correct language is robustness, objective sensitivity and constraint residuals, not generic GSA.

Validate conclusions

Browser optimization is pedagogical and exploratory. Use exported Python for serious validation.

8. Failure checks

  • 404 on model route: use workbench.html?model=... or model.html?model=...; both aliases should exist.
  • Unknown model: the model exists in Atlas but not in the workbench registry.
  • Slow stochastic page: reduce ensemble runs or use the legacy stochastic lab for specialized models.
  • Blank plot: check browser console, Plotly loading, and whether the card needs manual Run.
  • Misleading GSA label: browser result is only a quick screen unless the exported SALib workflow is run.
