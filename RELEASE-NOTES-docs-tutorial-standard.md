# Foko Lab documentation/tutorial standard update

This package keeps the current online legacy labs and the model-centered workbench, while replacing the user-facing documentation layer.

## Intentional changes

- Rebuilt `docs.html` as an operating-standard reference.
- Rebuilt `tutorial.html` as an action-based guide with direct routes, expected results, and failure checks.
- Preserved the primary navigation labels:
  - Home
  - ODE Lab
  - Optimization Lab
  - Steady-State Lab
  - Stochastic Lab
  - Model Atlas
  - Docs
  - Tutorial
- Removed stale version-history style documentation from the user path.
- Added clear rules for:
  - Model Atlas routing
  - Workbench vs legacy lab use
  - Analysis cards
  - GSA/sensitivity terminology
  - Exports
  - Browser trust limits

## Boundary

The core legacy labs are not redesigned in this package. The intentional documentation changes are limited to `docs.html` and `tutorial.html`.
