      Source criticism is part of studying

      Known issues in this edition

      The original PDF is unchanged. These independently checked notes flag two source issues; they are not a complete chapter-by-chapter scientific audit. Source pages and later qualifications remain available.

      Chapter 4 · Figure 4.1 · printed p. 37 / PDF p. 61

      The figure defines y = k*x/(K+x) but its final takeaway gives dy/dx = k/(K+x). For constant k and K, the quotient rule instead gives dy/dx = k*K/(K+x)^2. At k = 10, K = 2, x = 3, the correct result is 0.8, not 2. The worked example on printed p. 39 / PDF p. 63 is consistent with 0.8. The figure’s addition-node wiring and final forward-mode annotation should be corrected in the author source.

      Inspect Figure 4.1Compare the worked calculation

      Chapter 3 · printed CG listing · printed pp. 29–30 / PDF pp. 53–54

      The printed function enters the iteration before accepting an already-zero initial residual. Running A = I, b = [0, 0], x₀ = [0, 0] raises a non-positive-curvature error even though the system is already solved. The nonzero control A = I, b = [1, 2] returns [1, 2] in one iteration. The initial stopping check must come before constructing a nonzero search step. The later correction on printed p. 34 / PDF p. 58 describes this boundary, but does not repair the earlier listing.

      Inspect the printed codeRead the later qualification

      Both findings were checked against the supplied PDF. Their calculation record is included in the source preview’s validation folder. Do not describe this author edition as a fully corrected teaching release.
