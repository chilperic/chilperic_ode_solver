Import model / templates

Import a local declarative model: JSON/Model IR, model-table CSV, TXT/ODE, YAML, Python or JavaScript data dictionary, or the strict SBML reaction subset. Files are parsed locally and dictionary code is never executed. SBML rules, events, packages, delays and unsupported MathML are rejected instead of silently omitted.

Guide

Custom ODE model and method choice

This lab accepts user-defined models. The selected method controls how the browser interprets the model; exports remain the route for heavy or validated computation.

Own modelImport JSON/Model IR, model-table CSV, TXT/ODE, YAML, data-only Python/JavaScript dictionaries, or the validated SBML subset.
MethodsRK45/RK5/RK4/Heun/Euler run in browser; Radau/BDF/LSODA/DOP853 are exported for Python.
ApproachInitial-value simulation, parameter sweep, phase portrait, vector field and export.
