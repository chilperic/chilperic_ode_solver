One-locus model

Each generation applies viability selection, mutation, symmetric migration, then exact binomial sampling of 2N chromosomes. The browser refuses runs above 30 million Bernoulli draws rather than silently substituting an approximation.

Interpretation boundary

What this lab does not infer

This is a constant-size, non-overlapping, two-deme Wright–Fisher model at one biallelic locus. It does not estimate demography, ancestry, linkage disequilibrium, recombination, genotype likelihoods, relatedness, or selection from observed genomic data. Those require validated file formats, likelihoods, ascertainment models, and specialist external tools.
