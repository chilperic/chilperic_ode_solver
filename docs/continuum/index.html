What is—and is not—being simulated

Each generation samples parents with replacement (haploid Wright–Fisher sampling). Reproduction weights are proportional to exp[β(A − Amax)/10], where A is net assimilation in µmol m⁻² s⁻¹. Offspring inherit allocation plus independent Gaussian perturbations; negative fractions are truncated and the vector is normalized to sum to one. β = 0 removes assimilation selection; mutation = 0 preserves the initial homogeneous population. Invalid physiological solutions receive no reproductive weight; an entirely infeasible population stops with an error.

This is an explicit experimental fitness assumption. It does not establish that higher instantaneous assimilation increases seed production, drought survival or long-term fitness. It also omits the C2 photorespiratory glycine shuttle, which matters for interpreting intermediate Flaveria. Population size is fixed, and extinction dynamics are not modeled.

Physiology reuses the corrected leaf model: shared energy budget, CO₂ balances, hydraulics and heat. The uploaded CasADi code is retained as a source for audit, not silently substituted or described as independently reproduced.
