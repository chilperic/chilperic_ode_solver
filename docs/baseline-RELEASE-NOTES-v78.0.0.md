# FokoLab 78.0.0 — connected research release candidate

This release adds a substantive experiment and learning layer, not merely a visual skin.

## Implemented

One canonical ODE model across simulation, observations/fitting, local/global-range robustness and conditional scientific ML comparisons. The engine is dependency-injected and reuses strict Project normalization, the restricted expression compiler and canonical ODE integration. Dedicated-worker execution has a terminable budget and explicit bounded fallback. Settings, seeds, split indices, baseline comparisons and data provenance are saved with every calculation.

Four research dossiers connect biological questions to runnable models and falsifying tests. Twelve worked lessons provide derivations, 24 exercises with hints/solutions, 12 reasoning checks and persistent/exportable notes. A parameter-surrogate task separates unseen parameter tests from the time-holdout task. Residual correction is explicitly not an equation-level neural/UDE model. AI critique is optional text export, never automatic submission or a validity badge.

New Home, Workspace, Library and Learning use one isolated design system with native modal dialogs, contrast modes, responsive grids and tab keyboard behavior. Trajectories and comparisons have SVG descriptions and native tables/CSV. The heavy Plotly library is not loaded by the new routes. The specialist shell links to the new workflow; 20 specialist tools and the 259-entry catalogue remain.

## Reliability work

Immutable per-run snapshots, invalidation on edits, atomic rejected imports, review-before-apply fitting, draft-data/model guards, input-dependent fingerprints, run cancellation and saved evidence. Browser storage denial is nonfatal; write failure cannot resurrect obsolete persisted values over newer in-memory state. Full bundle export/import, same-engine CLI replay and independent SciPy trajectory export are included.

## Explicit boundaries

This is not a complete rewrite of all specialist engines or all legacy CSS. No universal automatic handoff between every lab, LLM service, neural-network training backend, scientific agent, Bayesian calibration, production stiff solver or empirical domain calibration was added. The protected C3–C4 implementation remains unavailable. Large computations and advanced inference belong in an external scientific workflow.

Full native HTTP/Worker, real-device, screen-reader and live deployment validation remain pending. Executed checks and their evidence are in VALIDATION.md. Archived v77 material is historical, not this release's certification.
