Docs

Use the right lab for the model.

Foko Lab is organized around model classes. Pick the lab, run a small case, then export when the computation becomes too heavy for the browser.

Core workflow

  1. Choose a lab or start from the Model Atlas.
  2. Load an example or paste a custom model.
  3. Select the method or modeling approach.
  4. Run a small diagnostic case.
  5. Export JSON, Python, SymPy, SciPy or figures when needed.

Labs

ODE Labcontinuous deterministic systems, sweeps and phase plots
Optimization Labobjectives, constraints and trade-offs
Steady-State Labroots, equilibria, continuation and SciPy export
Stochastic LabCTMC, Gillespie-style events, Monte Carlo and sample paths
Symbolic Labderivatives, Jacobians, scans, plots and SymPy export
Agent Labgrid rules, local states, network contacts and JSON export

Custom models

Each lab exposes an authoring route. Browser execution is suitable for small models. Use exports for stiff ODEs, large ABMs, calibrated inference, full sensitivity analysis or publication work.

Agent Lab notes

Custom rule code runs through agent-rule-worker.js with a worker timeout. multilayer spatial/social/transport contacts are available for browser-scale experiments.

Plot standard

Use the simplest plot that answers the question. A browser plot is an exploratory result unless it is validated externally.

Scientific limits

Symbolic Lab is not a full in-browser CAS. Agent Lab is not a full network-science package. Heavy computations should move to exported scripts.
