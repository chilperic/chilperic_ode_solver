# FokoLab 79.1 — identity and V6.17 material integration

This is an implemented **visual/product release candidate**, based on the recoverable core-access recovery package and numerical version **78.2.0**. The previous reply's v79.0.0 archive was not available in the runtime or retrieved through Files; no unverified changes from it are assumed. This release does not claim to be the “best” platform or establish competitive superiority through a user study.

## What changed

**A new mark and lab-symbol family.** The old F-shaped path/cube identity is replaced by two open orbital curves and a shared observation node. Thirty individually drawn vector symbols cover the twenty original labs plus supporting areas. Light/dark variants, monochrome mark, wordmark, favicon and touch icons are included. The mark is editorial identity, not a scientific diagram or a computed trajectory.

**Page color communicates location.** Seven application areas have separately named accents: model/mathematics, dynamics, populations/living systems, inference, decisions, scientific AI and learning. A header edge, active control and restrained icon/title accents identify the area; large surfaces remain neutral. Status/error colors and scientific series colors remain separate. The book's seven original parts use a separate source-derived sequence, with orange/gold darkened for readable screen text. Its part names and Roman numerals remain explicit.

**Original capabilities remain primary.** Home still opens Model Studio, the native labs and the full Model Atlas. All twenty labs retain their static method/example selector values, labels and disabled states. The 259 original catalogue records are byte-identical to the baseline. Two-up and Focus remain independent of plot selection. Guided workflows, the programme and the book are additions, not replacements.

**Search is bounded, not reduced.** Both retained shell families now display twelve search destinations at a time with Previous/Next controls and a result count. Original model destinations remain searchable; 27 latest-book chapters and 54 distinct practice destinations are additive. Book discovery metadata loads on opening search. The connected workspace's catalogue search metadata also loads on demand, keeping the existing JavaScript byte/request budgets rather than relaxing them.

**Responsive defects repaired.** The 320px research header keeps its navigation button onscreen. The stochastic reaction editor no longer overflows at tablet widths. Scenario controls wrap; public footers and the identity guide no longer clip text. Optional details remain disclosures; this does not guarantee perfect usability for every numerical result on every device.

**Small resilience fix.** The advanced-methods controller now catches denial of its optional history-URL update. This changes neither example parameters nor numerical calculation. The unchanged numerical cores, models and workers are tracked separately from this reviewed controller/presentation change.

## Boundaries that remain

Normal HTTP browser navigation was blocked by this environment. Rendered fixtures fulfill original source bytes in memory, simulate storage, and disable native workers to exercise the declared bounded fallback. They are not deployment or native-worker certification. Real persistence, PDF viewer behavior, screen readers, physical devices, actual visitor performance and unfamiliar-user usability remain unverified. Existing KaTeX mathematical font requests still depend on their external CDN; the new interface fonts use native system faces. No font binaries are included.

There is no new server, account system, live collaboration, automatic certificate, autonomous AI agent, clinical validation, or completed original-research transfer. Scientific ML and existing models retain their existing capability boundaries. The two underlying shell families remain; this release gives them a shared identity and interoperable appearance/search behavior rather than falsely claiming a complete framework rewrite.

## Book publication and privacy

The supplied author edition retains personal planning material on physical pages 6–9. `publication/book-approval.json` remains unapproved. The Pages workflow blocks its artifact upload until the exact edition is approved, but publishing the source repository or manually hosting the Pages ZIP bypasses that safeguard and exposes the PDF and its text index. Review `PUBLICATION_REVIEW.md` first. No live website or repository has been modified.
