Chilperic ODE documentation

Chilperic ODE is a browser workbench for exploring ordinary differential equations, parameter sweeps, phase portraits, heatmaps, and nonlinear optimization. The browser solver is for exploration and teaching. For stiff systems or serious constrained optimization, export Python and use SciPy, CasADi, or Pyomo locally.

Quick start

  1. Select a module: ODE, Parametric, or Optimization.
  2. Load an example or import a model file.
  3. Edit equations, parameters, initial values, or constraints.
  4. Click Run. In Parametric mode, click Sweep to evaluate parameter ranges.
  5. Choose left and right plots independently.
  6. Export PNG/SVG, CSV/JSON, or a runnable Python script.

Plot types

ODE: trajectory, 2D/3D phase portrait, vector field, Poincaré section, trajectory matrix.

Parametric sweep: heatmap, contour, bifurcation-style diagram, envelope/fan plot, parallel coordinates.

Optimization: samples, optimization path, convergence, objective–constraint trade-off.

Solvers

The browser supports Euler, Heun, RK4, RK5, and RK45-style adaptive integration. Python export supports SciPy solve_ivp targets such as RK45, DOP853, Radau, BDF, and LSODA.

Import formats

Use JSON for the most reliable model interchange. CSV, TXT/ODE, YAML-like files, Python files with an embedded ODE_LAB_CONFIG block, and basic SBML/XML reaction models are also supported. SBML import handles species, reactions, stoichiometry, global/local parameters, and MathML kinetic laws. Events, algebraic rules, assignment rules, units, and advanced SBML packages are intentionally ignored in the browser.

Export publication figures

  1. Run a model or parameter sweep.
  2. Choose the primary or secondary view.
  3. Open Figure settings.
  4. Edit the title, axis labels, colorbar label, size, font, line width, marker size, legend, and grid.
  5. Export SVG for manuscripts or PNG for slides.

Additional examples

The workbench separates core examples from additional research and teaching examples. Core models stay visible for fast learning; additional models live in their own panel so the main workflow stays clean. See the dedicated Model Atlas for authors, model purpose, and exploration notes.

  • FA metabolism bistability: PhD-inspired four-state model with acetyl-CoA, malonyl-CoA, fatty acids, and triglycerides.
  • FADNS with CoA sequestration: refined PhD-inspired semi-mechanistic model with FAS intermediates, CoA release, and inhibitory ECoA formation.
  • Love–hate oscillator: a two-variable Romeo–Juliet / Strogatz-style oscillator.
  • Braess routing dynamics: a route-choice model for congestion and shortcut effects.
  • Ziegler destabilization: a structural-dynamics example where added stiffness or follower load can destabilize motion.
  • Calvin cycle mini-model: a minimal photosynthesis-inspired model for PGA and RuBP pools.

SBML import boundary

SBML support is deliberately lightweight. The browser converts ordinary reaction-network SBML into ODEs using stoichiometry and kinetic-law MathML. For full SBML validation, model exchange, events, rules, units, or packages, use a specialist SBML toolchain and then import a reduced reaction model here.

Interface themes

The workbench includes eight themes: Aurora, Clarity, Ocean, Lavender, Midnight, Slate, Paper, and Forest. Use lighter themes for teaching/projection and dark themes for long work sessions.
