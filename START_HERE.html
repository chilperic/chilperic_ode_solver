Integrated Update

The actual application and editable source are in site/. The original 79.1 scientific tools are retained and extended.

Start locally

Extract the whole ZIP. Open a terminal in this folder, then run:

python3 serve.py

On Windows, double-click START-FOKOLAB.bat or run py -3 serve.py.

Keep the terminal open. The application opens at http://127.0.0.1:8765/. No Node, npm, account or source editor is needed to use it. Opening the application directly as a file is not supported because of module/worker restrictions.
