Tutorial

Run one model.

Start small, change one parameter, then add plots or export.

WorkbenchModel AtlasDocs

1. Equation model

  1. Open ODE Lab.
  2. Load SIR, Lorenz or FADNS.
  3. Run a trajectory and one phase plot.
  4. Use Open in Symbolic or Open in Steady-State when structure matters.
  5. Export Python for local validation.

2. Symbolic route

  1. Open Symbolic Lab.
  2. Select Logistic growth or Lotka–Volterra.
  3. Press Analyze.
  4. Use expression, phase-line, time-course or vector-field plots.
  5. Export SymPy for exact work.

3. Agent route

  1. Open Agent Lab.
  2. Select a built-in example.
  3. Read the rule definition only if the dynamics are unclear.
  4. Step once, then run.
  5. For custom rules, return a valid state index for the selected model. Slow rules stop at the worker timeout.

4. Workbench route

  1. Open Workbench or Model Atlas.
  2. Choose a curated model.
  3. Change one parameter.
  4. Compare plots only when each plot answers a specific question.

Failure checks

  • Symbolic plot blank: check variable names, numeric scope and ranges.
  • Agent result unclear: switch plot mode and inspect the rule.
  • Run too slow: reduce grid size, time span, iterations or export locally.
  • Scientific claim too strong: validate outside the browser.
