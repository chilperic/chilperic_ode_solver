Shared workflow

  1. Select a model from the library or Model Atlas.
  2. Edit equations, parameters, events or optimization objectives in the middle panel.
  3. Run, solve or optimize from the sticky action bar.
  4. Read the status strip and metrics.
  5. Use the two-plot workspace and diagnostics tab.
  6. Export CSV, JSON, Plotly JSON or Python starter code.

Labs

ODE Lab

Deterministic ODE simulation, phase portraits, parameter sweeps, vector fields, Poincaré sections and Python solve_ivp export.

Optimization Lab

Constrained nonlinear optimization, metaheuristics, convergence plots, feasibility diagnostics and SciPy export.

Steady-State / Algebraic Lab

Algebraic systems f(x,p)=0, Newton solves, residuals, stability classification, alternative equilibria and continuation.

Stochastic Lab

CTMC/Gillespie models, branching processes, random walks, stochastic decision models, ensemble plots and stochastic exports.

Exports

Every lab is designed for reproducibility. Use model JSON to save the model, wide CSV for spreadsheet inspection, long CSV for tidy analysis, Plotly JSON for recreating figures, and Python export for external computation. Browser results are intended for exploration and teaching, not regulatory-grade validation.

Known scope

  • Browser solvers are best for small to medium exploratory models.
  • Stiff ODE methods such as BDF, Radau and LSODA are exported to Python rather than solved directly in the browser.
  • Large stochastic ensembles should be moved to Python after prototyping.
  • SBML import supports useful basic cases but not the full SBML standard.
