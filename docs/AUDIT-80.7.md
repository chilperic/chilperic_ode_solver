# FokoLab 80.7 audit

The reported screenshot combined a 50% GDC conditional slice with a global legend, a strict allocation cutoff, and a failed Niger run while retaining old results. These are distinct problems.

## Repairs

- One shared diagnostic classifier replaces competing browser/server rules. C2 requires calculated daylight activity rather than merely a nonzero localization setting. Small nonzero PEPC activity can qualify as Type I-like.
- The exploratory C3 floor defaults to 80%, is configurable, and has a 70/80/90% sensitivity table. A 90% mesophyll cap occupies 1% of a continuous simplex; 80% gives 4%, before activity/feasibility restrictions. Counts of numerical samples are explicitly distinguished from area and evolutionary probability.
- Legends enumerate only feasible classes in the selected slice, including Other. Absent classes are named with an explanation. GDC slice selection is visible beside the plot, with quick comparison at matched stomatal conductance.
- Figures identify the actual completed forcing and seed. Errors and changed inputs prominently identify retained previous results. Starting conductance is explicit, and infeasible starts are never silently replaced.
- Strategy frequencies use exact playback time. Display controls do not mark scientific inputs stale. Original native plant/leaf renderers remain unchanged.
- The main test command targets current public/private paths rather than the obsolete dist root. Archived numerical contracts run unchanged against current served cores. A statistics workspace import used browser-only window outside its guard; repaired.

## Verification scope

All 76 HTML pages: local assets/links, duplicate IDs, JSON parsing. Syntax checks for 244 served JavaScript files. Nineteen core contract suites across ODEs, steady states, stochastic models, optimization, population genetics, bifurcation, sensitivity, data, PCA, statistics, fitting, linear algebra, networks and machine learning. Native plant/leaf/soil/T-cell conservation and analytical benchmarks; eight Research Hub adapters and record/storage lifecycle. Four hundred independent warm/cool replicate checks and threshold-invariance, stream/final consistency and failed-start checks. Browser verification covers completed runs, slice switching, playback, failed-run retention and responsive layout.

These checks support implementation consistency; they are not experimental validation of the full biological model or a proof that no defects remain.

## Remaining scientific work

Nitrogen conversion remains queued, with explicit capacity labels until enzyme-specific parameters are sourced. C2 transport/nitrogen costs and evolving anatomy are not calibrated. Region cutoffs are transparent exploratory conventions. Endpoint frequencies depend on forcing, objective, mutation kernel, grid, horizon and parameters; they are not species prevalence or inevitable evolutionary destinations.
