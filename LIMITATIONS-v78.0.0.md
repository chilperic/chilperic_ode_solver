# FokoLab v78.0.0 limitations

Release candidate. Native HTTP browser tests and live GitHub Pages deployment are not certified in the execution environment.

The new connected workspace handles bounded ODE experiments (up to 20 states, 30 parameters; 1–3 fitted parameters; one-parameter polynomial surrogates). It preserves specialist labs, not a universal shared state across all their formats. Explicit JSON transfer opens the same ODE model in advanced Studio.

The four pathways are transparent reductions or benchmarks, not calibrated physiological predictors. The protected C3–C4 implementation remains unavailable. Synthetic observations are explicitly labelled. Finite-difference sensitivity is local, bands are independent-uniform simulation quantiles, fitted parameters do not establish identifiability, and the residual hybrid is not a neural differential equation.

AI review is an export only. No language model service, cloud compute, API key, authentication or API proxy is included.

No claim of complete WCAG conformance, empirical biological validity or production certification is made. Local browser storage is not a backup; export projects. See VALIDATION.md for executed checks and boundaries.
