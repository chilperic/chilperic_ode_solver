Workbench standard

Workbench remains the default model-centered route for curated examples, custom ODE systems, 2D optimization models, plot cards, diagnostics and exports.

Specialist labs

Use specialist labs when the question is specifically about ODE integration, optimization, steady states, stochastic simulation, symbolic structure or agent rules.

Symbolic Lab

Symbolic Lab is for analysis before simulation. It supports edited equations, LaTeX preview, simplify/expand/factor, differentiation, requested integration, Jacobian generation, numeric equilibrium scans, 1D and 2D plots, time courses, vector fields, nullcline scans and parameter root sweeps.

ModeUse
Expression / phase lineInspect a single RHS, roots and sign structure.
Time courseNumerically integrate the current RHS from the numeric scope.
Vector field / nullclinesInspect 2D flow and approximate zero sets.
Parameter sweepScan root candidates of a 1D system over one parameter.

Agent Lab

Agent Lab keeps long scenario descriptions in the Model Atlas and exposes compact dropdown selectors, the rule, the state legend, parameter meanings and diagnostic plots. Built-in examples are starting points. Custom local rules are executed inside agent-rule-worker.js rather than on the UI thread. The editor exposes cell, neighbors, counts, params, rand, x, y, t, trait, memory and dt. The main thread terminates slow custom rules to avoid freezing the page.

PlotUse
PopulationCounts for states 1, 2 and 3 over time.
CompositionCurrent spatial state counts.
PhaseRelationship between two state populations.
EventsBirth, death, infection, recovery, mutation or custom-change counts.
TraitTrait distribution for plant/evolution examples.
Network / layersDegree distribution and mean degree by spatial, social and transport layers.

Custom rule variables: cell neighbors counts params rand x y and t. Start from the Agent Model Atlas when you need scenario context, then run the compact page. In multilayer mode, neighbor counts merge selected spatial, social and transport/contact layers.

Custom models

  • Workbench: custom ODE and 2D optimization JSON.
  • Symbolic Lab: edited equations, variables, parameters and numeric scope.
  • Agent Lab: custom local JavaScript rule, custom model JSON, approach comparison, graph/network topology, multilayer spatial/social/transport contacts, continuous vs discrete time update plus JSON import/export.

All labs model-authoring standard

Every modeling lab should let the user implement or import a model, choose a method or modeling approach, run diagnostics, and export the model state. The browser is an exploratory layer, not the final validation layer.

Agent Lab execution standard

The Agent Lab page should stay compact: select example, approach, update scheme, topology and plot mode, then run. Longer scenario explanations belong in the Model Atlas.

Approach selector

Rule-based, statechart, adaptive-learning and graph/network options are selectors for the modeling contract. They should change the rule template and interpretation, not become page text.

Custom model route

Use custom model JSON to define states, colors, parameter labels, defaults, topology and rule code. Rule code is compiled in a Web Worker sandbox and returns either a state index within the model state list or an object such as {state, trait, event}.

FADNS tracker

The FADNS agent example tracks Acetyl-CoA, Malonyl-CoA, chain intermediates, C14, C16, C18 and CoA. It is a toy event/state model, not a calibrated replacement for the FADNS ODE model.

Multilayer network mode

multilayer_social combines spatial adjacency with a social contact layer. multilayer_transport adds longer-range hub/transport contacts. This is a usable browser ABM engine for prototypes, not a full professional network-science package.

Plot standard

Every plot should answer one question. If a plot is blank, first check numeric scope, variable names and ranges. If a plot is visually attractive but scientifically unclear, treat it as a sketch, not evidence.

Exports

Use JSON for model state, CSV for data where available, SVG/PNG for figures, Python/SymPy/SALib scripts for external validation, and Agent Lab JSON for reproducible grid-rule scenarios.

Scientific limits

  • Browser simulations are exploratory unless validated externally.
  • Symbolic Lab is not a full in-browser CAS.
  • Agent Lab custom code is local and prototype-grade.
  • Heavy stiff systems, large ABM, calibrated inference and publication claims should move to exported Python/R/Julia workflows.
