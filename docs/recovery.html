Evidence

Source and transformation manifest · Executed test results

Passing software tests does not validate biological parameters, prove a bistability interpretation, or establish experimental agreement. Browser runs are headless Chromium checks, not physical-device or unfamiliar-user studies. Old release evidence applies only to its stated release.

Export and access limits

Native JSON, CSV, image and figure-export controls are retained. The original host refused three advertised ZIP archives with HTTP 403: its full-site ZIP, plant Python ZIP and leaf Python ZIP. Their contents have not been recovered or replaced with invented native-Python implementations. The existing additional teaching modules retain their own separately labelled Python exports.

Private planning PDFs and font binaries are excluded from newly recovered distributions. The existing public Scientific Mastery companion remains accessible. Historical weather calls require their external data service; an offline or failed response is not silently replaced by synthetic weather.

Saved experiments

Existing record schemas are preserved. A different website origin cannot read the old site's browser storage. Export a record on that site and import it in the recovered saved-experiment workspace to move personal runs.
