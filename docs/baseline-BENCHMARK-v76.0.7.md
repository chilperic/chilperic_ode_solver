# Foko Lab v76.0.7 platform benchmark

This benchmark guides product design; it does **not** claim numerical or feature parity with mature desktop, server or commercial scientific platforms.

| Reference | Design lesson applied in v76.0.7 |
|---|---|
| VCell | Keep model definitions, experiment settings and results attached to one project. |
| SimBiology | Make construction primary and simulation, fitting, sensitivity and design compatible downstream tasks. |
| COPASI | Expose algorithm, status, diagnostics and reproducible reports beside results. |
| Tellurium | Preserve a low-friction route from editable mathematics to a scriptable experiment. |
| OpenCOR | Separate model content from simulation-experiment settings and support adjustable/dockable scientific workspaces. |
| NetLogo | Keep model controls and live visualization usable while preserving a distinct advanced authoring route. |
| Cell Collective | Use visual model interaction where network structure benefits from it. |
| BioUML | Treat analyses as project operations rather than disconnected demonstrations. |
| Simulink | Keep model, experiment, run controls, diagnostics and comparisons in one workspace. |
| COMSOL | Organize complex work as model → study → results, with contextual rather than decorative visualization. |

## Measurable dimensions

- **Scientific reliability:** finite-input validation, solver evidence, seeded stochastic methods, strict standards boundaries, independent references and stale-result safety.
- **Model ownership:** blank-model route, editable equations/initials/parameters/time, multi-format local interchange and specialist-lab handoff.
- **Platform stability:** one application shell, one plot lifecycle, bounded browser budgets, deterministic release gates and recoverable projects.
- **UX:** resizable desktop authoring/results split, keyboard operation, phone task panels, stable Home route, optional Atlas and direct trust/creator access.
- **Modern GUI:** restrained scientific palette, lab-family orientation accents, compact type scale, responsive navigation, accessible focus and relevant 3D.
- **Honest interoperability:** Model IR is internal; SBML is a strict subset; SED-ML, CellML and OMEX are recognized but not overstated.

Foko Lab's differentiator is a browser-native modeling workspace that combines editable mechanistic, population, agent, data-driven, Bayesian, optimization and sensitivity workflows with explicit evidence boundaries. Its examples and Atlas strengthen model creation but do not define the product.

Primary standards references: [SBML Level 3](https://sbml.org/documents/specifications/level-3/), [SED-ML](https://sed-ml.org/), [CellML 2.0](https://www.cellml.org/cellml/2.0), [OpenCOR simulation experiments](https://opencor.ws/user/plugins/simulation/simulationExperimentView.html), [NetLogo Interface tab](https://docs.netlogo.org/7.0.3/interfacetab), and [SimBiology SBML support](https://www.mathworks.com/help/simbio/gs/simbiology-and-sbml.html).
