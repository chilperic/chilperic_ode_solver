# Foko Lab v77.2.0 — modeling-platform benchmark

This benchmark is a product-positioning and engineering checklist, not a claim of numerical or feature parity. Foko Lab deliberately combines browser-native model authoring with transparent, bounded scientific methods; specialist packages remain the reference for many production workflows.

| Dimension | Foko Lab target | Relevant specialist comparison |
| --- | --- | --- |
| Scientific reliability | Finite-input validation, explicit assumptions, diagnostics, independent reference probes, honest capability labels | COPASI, Tellurium, VCell, SimBiology |
| Platform stability | One canonical scientific core per computation, offline vendored runtime, deterministic release gate, explicit unsupported-format failures | Mature desktop/server modeling environments |
| UX | Model-first authoring, resizable input/results workspace, task rail, keyboard/touch navigation, creator/trust access | COMSOL Model Builder, Simulink modeling workflows |
| Modern GUI | Responsive workbench, compact command search, subject/lab identity, accessible semantic plots, mobile task mode | Contemporary scientific notebooks and simulation applications |
| Model interchange | TXT/ODE, JSON, Python/JS object/dictionary, YAML, CSV, bounded SBML/CellML/SED-ML/OMEX paths | BioUML, VCell, COPASI, Tellurium |
| Population/evolution | Finite-population genetics, agent simulation, fitness landscapes, contextual live 3D | Cell Collective and specialist population/ABM environments |
| Analysis breadth | Local/GSA sensitivity, Sobol, Morris, fitting, statistics, CMA-ES, Bayesian references, AI/SciML | Specialist packages remain deeper in each individual domain |

The important competitive criterion is coherence: a user's model should remain the same scientific object as it moves from definition to simulation, analysis, diagnostics, visualization, and export. The Atlas is supporting infrastructure, not the primary product surface.

Foko Lab does **not** claim numerical or feature parity with COMSOL, MATLAB/Simulink/SimBiology, VCell, COPASI, Tellurium, Cell Collective, BioUML, Stan/PyMC, SALib, SciPy, or dedicated HPC solvers. The honest goal is a smaller browser-scale workbench whose supported computations are inspectable and reproducible.
