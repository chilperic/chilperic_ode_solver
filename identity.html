One identity, different scientific roles

The mark

A compact F-shaped path with a distinct observed endpoint. One construction serves the app, wordmark and favicon.

The colour

Ink for structure; copper for emphasis; sage for biological pathways. Status and series also have text labels.

The representation

Use equations, data and simple process symbols. No decorative plot is presented as computed evidence.

Colours and editorial typography connect to the companion career programme. Controls use the system font; headings use native Georgia. No external font request is required.
